# M3 benchmarks: counterfactuals on the real snapshot

**Machine:** the same container as before (4 vCPU Xeon @ 2.1 GHz, native
release, single-threaded). **Data:** NYC 311 `3b42e46a…` (7,111,809 rows).
**Harness:** `cargo run --release -p receipts-bench --bin m3 -- <snapshot dir>`.
Peak RSS was 1.33 GB.

**Plan:** noise complaints closed on or after they were created, hours to
close, grouped by borough (count, median, mean), sorted by median. The
base execution took 627 ms.

## Exclusions: incremental vs full re-run

Every row's output was compared bit for bit between the two methods, and
all were identical.

| Exclusion | Rows | Method | Incremental | Full re-run |
|---|---|---|---|---|
| One Bronx noise complaint | 1 | incremental (1 group, 443k members) | 63 ms | 2,494 ms |
| One row the plan filters out | 1 | unchanged | 4 µs | 1,427 ms |
| 1,000 random rows | 1,000 | incremental (5 groups) | 132 ms | 1,099 ms |
| Every row created at exactly midnight (`KI-created-midnight`) | 4,650 | incremental (5 groups) | 126 ms | 1,356 ms |
| All 54 "Unspecified" noise rows (the group disappears) | 54 | incremental (1 group) | 5 ms | 1,062 ms |
| 100,000 random rows | 100,000 | incremental (5 groups) | 131 ms | 1,317 ms |

The incremental cost tracks the size of the affected groups (the Bronx is
443k rows), not the table or the number of excluded rows.

**Finding:** excluding the 4,650 midnight-timestamped records (a known
issue: date-only precision) barely moves this result. Only 32 of them are
noise complaints that pass the filter. The medians don't change at four
decimals, and the means move in the fourth decimal (Bronx 4.0527 h to
4.0528 h).

## Contributions (leave-one-out): Bronx median

- **443,530 leave-one-out values in 58 ms**, all exact. Three were
  spot-checked against real single-row exclusions and were identical.
- **Finding: no single row moves the Bronx median** (1.548611 h, about
  92.9 minutes). Source times are mostly recorded to the minute, so many
  complaints share the exact median duration, and removing any one of them
  leaves an equal value in the middle. For this claim, the median is
  robust to any single record. A UI that ranks rows by influence should
  say so plainly rather than show 443k zeros.
- Mean contributions for the same group take 9 ms and are marked
  `exact: false` (decimal `total − x`).
